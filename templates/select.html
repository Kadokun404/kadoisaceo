OpenUI / CSS Spec Testing

Customizable <select> Playground

Uji coba langsung kode CSS Wolep: appearance: base-select & pseudo-elemen ::picker(select).

1. Live Preview (Klik Dropdown Di Bawah)

2. Source Code CSS yang Diuji

/* Aktifkan mode kustomisasi penuh */
select,
::picker(select) {
  appearance: base-select;
}

/* Kotak dropdown popup yang muncul */
::picker(select) {
  border: 1px solid #ccc;
  border-radius: 8px;
  background-color: #ffffff;
  padding: 4px;
  margin-top: 4px;
}

option {
  padding: 8px 12px;
  border-radius: 4px;
}

option:hover {
  background-color: #f0f4ff;
}
💡 Catatan Kompatibilitas Browser:
Fitur ini adalah spesifikasi resmi terbaru OpenUI / W3C. Sudah aktif di Chromium 130+ (Chrome / Edge / Brave) atau via flag chrome://flags#enable-experimental-web-platform-features. Pada browser yang belum support, browser tetap menampilkan select bawaan secara graceful tanpa error.
